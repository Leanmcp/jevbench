\section{Discussion}

\paragraph{Calibration is the binding constraint.} The largest single improvement available to any model in this study comes from moving the decision threshold: 21.5 points for the commercial model on prompt injection, 18.9 for djev-0.1 on Aegis responses. Since these systems are deployed as gates whose threshold determines an action, this changes which actions a deployed system takes. Threshold selection belongs on a calibration split, and vendors should publish a recommended operating point, since integrators otherwise default to 0.5.

\paragraph{The interface admits non-overlapping competence.} A 421M model at chance on four multi-option slices reached 93.0\% on jailbreak classification with an AUROC of 0.998, and scored above djev-0.1 on prompt injection at the default threshold. Buyers of this model class should evaluate on their own decision shape, and benchmark designers should resist reporting an aggregate score.

\paragraph{Reading a question and choosing among options is the discriminating capability.} The gap between models is smallest on short binary safety decisions, where all three score between 93.0\% and 97.5\% on jailbreak classification, and largest on set-of-choices knowledge tasks, where accuracy on MMLU-Pro ranges from 12.5\% to 80.6\%. Option-order sensitivity follows the same pattern.
