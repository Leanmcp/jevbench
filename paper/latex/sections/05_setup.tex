\section{Experimental setup}
\label{sec:setup}

We evaluate three systems that expose the typed-decision interface. They differ
in architecture, in how much of them is public, and in where they run.
Table~\ref{tab:systems} summarises them.

\paragraph{Jev 1.13 (closed source).} Jev is a commercial typed-decision model
from TypeSafe AI \citep{typesafe2026jev}. It is available only through the
vendor's HTTP API. Its weights, architecture, parameter count and training data
are not published, and no open-source version exists. We therefore treat it as a
black box: every result we report for Jev describes the deployed service, as a
customer reaches it, under the version string \texttt{jev-1.13.0}.

\paragraph{djev-0.1 (open source, diffusion language model).} djev is an
open-source server that implements the typed-decision interface on top of a
general-purpose language model \citep{djev2026}. Its backbone is DiffusionGemma
26B-A4B \citep{diffusiongemma2026}, an open-weight text diffusion language model
from Google DeepMind. A diffusion language model does not generate one token at a
time; it starts from a block of masked tokens and refines the whole block in
parallel over several denoising steps. DiffusionGemma is a mixture-of-experts
model with 25.2B total and 3.8B active parameters, and it accepts text and
images. djev serves it with vLLM \citep{kwon2023vllm}, runs a single denoising
step per request, and reads the probabilities of the declared labels at the
answer position, as in Equation~\eqref{eq:restricted}. We pinned the djev source
at revision \texttt{3ce907e} and ran it on one NVIDIA A100 80\,GB GPU.

\paragraph{Laya 421M (open source, encoder).} Laya \citep{laya2026} is an
open-source decision model of about 421M parameters. It is not a generative
language model. A ModernBERT-large encoder \citep{warner2024modernbert} reads the
question, the options and the state as one sequence, two further transformer
layers follow, and a scorer assigns one logit per option; a softmax over these
logits gives the returned distribution. We ran the English checkpoint locally on
an Apple M3 Pro laptop, where its default context is 512 tokens.

\paragraph{Identical inputs.} All three systems received the same case files,
built once by the adapters of Section~\ref{sec:adapters}, with one typed question
per request. For every case we record the decision, the full probability vector,
latency, input and output token counts, and any error. The records exclude the
state text, so the released predictions remain publishable for sources whose
text cannot be redistributed.

\paragraph{Sampling controls.} For djev we fixed \texttt{seed=0} and
\texttt{samples=1} and sent requests six at a time. The Jev API exposes no seed
or sampling control. Each system was run once; Section~\ref{sec:limitations}
discusses the resulting run-to-run variance.

\paragraph{Cost and duration.} The djev text suite completed 8{,}016 cases in
19.4 minutes with zero errors, using 51 minutes of A100 time in total including
model startup. The hosted API consumed 6.03M input tokens.
